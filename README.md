# Sortech-Infra · GitHub 프로필

Sortech-Infra의 GitHub 조직 소개를 관리하는 저장소입니다.

조직 메인에 표시되는 내용은 **[profile/README.md](profile/README.md)**에서 수정합니다.

공개 조직 프로필을 표시하려면 이 `.github` 저장소를 공개 상태로 유지하고, 변경 사항을 기본 브랜치에 반영해야 합니다.

[GitHub 조직 프로필 설정 안내](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile)
